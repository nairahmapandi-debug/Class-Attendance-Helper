# Class Attendance Helper

## Project Purpose
The purpose of Class Attendance Helper is to help teachers record, manage, and monitor student attendance easily and efficiently. It aims to reduce manual recording errors and keep attendance information organized and accessible.

## Planned Features
1. Student Information Management
Allows teachers to add, view, and manage student information.
2. Attendance Recording
Allows teachers to record whether students are Present, Absent, or Late.
3. Attendance Reports
Generates attendance summaries and reports to help teachers monitor student attendance.
